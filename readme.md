# GOODSPRINGS — облачная версия

Данные хранятся в **Supabase** → новость, добавленная на компьютере, сразу видна на телефоне и у всех игроков.

## Быстрая настройка (один раз)

### 1. Создай проект Supabase
1. Зайди на https://supabase.com и зарегистрируйся
2. New Project → имя `goodsprings`, придумай пароль БД, регион ближе к тебе
3. Дождись создания проекта (1–2 минуты)

### 2. Создай таблицы
1. В меню слева: **SQL Editor** → New query
2. Открой файл `SETUP.sql` из этой папки
3. Скопируй **весь** текст и вставь в редактор
4. Нажми **Run**

### 3. Скопируй ключи
1. **Project Settings** (шестерёнка) → **API**
2. Скопируй:
   - **Project URL**
   - **anon public** key

### 4. Вставь ключи в сайт
Открой файл `js/config.js` и замени:

```js
SUPABASE_URL: 'https://xxxxx.supabase.co',
SUPABASE_ANON_KEY: 'eyJhbGciOiJI...',
```

### 5. Залей на Netlify
- Перетащи всю папку сайта в Netlify (или замени файлы в существующем сайте)
- Готово

## Пароль админки
По умолчанию: `goodsprings`  
Меняется в `js/config.js` → `ADMIN_PASSWORD`

## Что дальше
После настройки:
- Добавляешь новость в админке → она сразу на всех устройствах
- Объявления с модерацией работают так же
- Обращения к мэру и предложения — тоже в общей базе

Если что-то не работает — открой консоль браузера (F12) и посмотри ошибки. Чаще всего забыли вставить ключи или не выполнили SETUP.sql.
